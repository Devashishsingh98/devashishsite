pdflens.in

PDF Lens

Reading a dense document normally means leaving the page to ask a chatbot. PDF Lens keeps the answer beside the sentence you highlighted.

What shipped

  • Highlight any sentence, then pick Explain, Teach, Example or Code
  • Answers open nested, so the thread never disappears mid-read
  • Chat scoped to the document, with each answer tied to its page
  • Embeddings run locally, so the file does not leave the machine
  • In testing now. The repository stays private until it ships
  • React
  • Express
  • pdf.js
  • RAG
  • Local embeddings

satpath.in

SAT PATH

A weekly Hindi newspaper in Durg and Bhilai, in print since 2008. They needed a desk that files seven days a week, not a page that waits for Thursday.

What shipped

  • Hindi first, with a full English edition at /en
  • Thursday e-paper, unlocked by a paid subscription
  • Razorpay checkout at 49 rupees for 30 days and 499 for a year
  • Weather, Sensex and Nifty across the masthead
  • Advertise, donate, grievance and legal pages
  • Sections, search and an editor desk for daily filing
  • Next.js
  • TypeScript
  • i18n
  • Razorpay
  • Vercel
